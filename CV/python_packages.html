Metabolic modeling & microbial ecology

ModelSEEDpy-freiburgermsu

v0.3.1.5 · 7 releases · December 2023 · 15,846 downloads · GitHub · docs
  • My release channel of ModelSEEDpy — the toolkit for reconstructing and analyzing genome-scale metabolic models with ModelSEED, where I am a core developer.
  • Publishing my working branch made in-progress community-modeling features pip install-able for collaborators without waiting on an upstream release.

dFBApy

v0.0.4 · 4 releases · May 2022 · 8,031 downloads · GitHub
  • An API that simulates dynamic Flux Balance Analysis (dFBA) of BiGG models, which propagates metabolite concentrations through time instead of resolving a single steady state.
  • The module consumes the enzyme kinetics that are assembled by the BiGG-SABIO module.

CommScores

v0.0.10 · 4 releases · August 2023 · 6,532 downloads · GitHub · docs
  • An API that quantifies the metabolic interactions between members of a microbial community, which distinguishes syntrophy from competition for the same resources.
  • I am the lead developer of this module, which consolidates numerous interaction scores from the literature into a single programmatic interface.

BiGG-SABIO

v0.0.1 · 1 release · February 2022 · 5,152 downloads · GitHub
  • An API that scrapes SABIO-RK for the enzyme kinetics of every reaction in a given BiGG model.
  • The resulting kinetics tables parameterize the dFBA simulations of the dFBApy module.

OptlangHelper

v0.0.3 · 3 releases · September 2026 · 2,744 downloads · GitHub
  • An API that constructs Linear Programming models for Optlang, which is the solver-agnostic optimization interface that underlies COBRApy and ModelSEED.
  • Variables, constraints, and objectives are defined as named tuples, which removes the boilerplate of assembling each new optimization problem by hand.
  • This is my most recently updated package.

Genomics & sequence analysis

Codons

v0.0.10 · 10 releases · April 2022 · 35,214 downloads · GitHub
  • An API that conducts the central dogma of biology — the transcription and translation of an arbitrary genetic sequence — and executes BLAST results for protein and genetic sequences.
  • The module exports FASTA-formatted files of the processed sequences, and interfaces with BLAST databases to identify them.

gpusw

v0.2.0 · 2 releases · June 2026 · 1,390 downloads · GitHub
  • An API that scores Smith-Waterman (local) and Needleman-Wunsch (global) sequence alignments on the GPU, with BLOSUM substitution matrices, from a kernel that is compiled at runtime.
  • The runtime kernel compiles through CUDA (CuPy/NVRTC) on NVIDIA hardware and through Metal (PyObjC) on Apple Silicon, so neither nvcc nor Xcode must be installed beforehand.
  • The module requires Python 3.10 or newer.

Chemistry, water treatment & kinetics

ChemW

v0.3.5 · 28 releases · June 2022 · 110,665 downloads · GitHub · docs
  • An API that precisely calculates the MW from any chemical formula, including inorganic complexations and decimal stoichiometry, to the appropriate significant digits.
  • The module also accepts protein sequences of one- or three-letter codes, and common chemical names that are recognized by PubChem.
  • The module further offers the ability to refine PHREEQC databases into programmable JSON files.
  • The aforementioned use-cases of ChemW were applied in the ROSSpy module, and this is my most downloaded package.

ROSSpy

v0.1.7 · 28 releases · June 2022 · 63,884 downloads · GitHub · docs
  • An API and UI that simulates the geochemical reactive transport of Reverse Osmosis desalination.
  • The module importantly predicts mineral precipitation, which causes scaling and module destruction.

hillfit

v0.1.7 · 18 releases · September 2022 · 59,255 downloads · GitHub
  • An API that calculates regression according to the biochemical Hill-equation for a set of data, co-authored with Hiroaki Imoto.
  • The module exports a regression plot with the R2, a TXT file of the equation and parameter values, and provides API access to all components of the equation.
  • The module was critically applied in refining the predictions of the PDIpy module.

PDIpy

v0.0.5 · 5 releases · April 2022 · 14,188 downloads · GitHub
  • An API and UI that predicts the log-reduction of a bacterial solution or biofilm colony from Photodynamic inactivation.
  • The module applies chemical kinetics to fundamentally model membrane oxidation over the course of time, and with the parameterized experimental conditions.
